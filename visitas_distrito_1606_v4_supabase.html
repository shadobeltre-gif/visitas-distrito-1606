📖 Manual del Administrador

📋 SISTEMA DE CONTROL DE VISITAS — MANUAL COMPLETO

Este manual describe todas las funciones del sistema, cómo administrarlo y cómo configurarlo para otras instituciones.

1️⃣ Acceso al sistema

El sistema tiene 3 niveles de acceso:

RolUsuarioContraseña inicialPermisos
👑 Administradoradminadmin123Acceso total, configuración, usuarios
👤 Operadoroperadorop2024Registrar entradas y salidas
👁️ Consultaconsultavis2024Solo ver registros, sin modificar

⚠️ Importante: Cambia las contraseñas por defecto inmediatamente desde Menú de usuario → Cambiar contraseña.

2️⃣ Registrar una entrada
  1. Ve a 📥 Registrar Entrada en el menú
  2. Selecciona el método de captura: teclado, cámara QR, escáner o lector USB
  3. Cámara QR/Barcode: haz clic en "▶ Iniciar cámara QR" y acerca el documento al recuadro naranja. Los datos se llenan automáticamente
  4. Lector USB/HID: selecciona el método HID, haz clic en el campo "Número de documento" y pasa la tarjeta por el lector
  5. Si el visitante ya estuvo antes, el sistema carga sus datos automáticamente
  6. Completa los campos obligatorios: Nombre, Documento, País, Centro y Motivo
  7. Opcionalmente toma una foto del visitante en la pestaña "📸 Foto"
  8. Presiona 💾 Registrar entrada — se imprime el ticket automáticamente
3️⃣ Registrar una salida
  1. Ve a 📤 Registrar Salida en el menú
  2. Escribe el nombre, documento o ID del visitante en el buscador
  3. Haz clic en 🚪 Salida en el resultado
  4. Confirma — el ticket de salida se genera automáticamente
  5. También puedes registrar salidas desde 🟢 Activos ahora o desde 📋 Todas las visitas
4️⃣ Reportes y exportación

📊 Dashboard: estadísticas generales, gráficas por país, centro y motivo, actividad reciente en tiempo real.

📅 Reporte Diario: selecciona cualquier fecha y obtén el reporte completo de ese día. Usa el botón 🖨️ para imprimirlo o guardarlo como PDF.

📋 Todas las visitas: filtra por nombre, país, centro, motivo, estado y rango de fechas.

Exportar datos:

  • 📗 Excel (.xlsx) — columnas separadas, colores, 3 hojas (visitas, resumen, activos)
  • 📄 CSV — compatible con cualquier programa
  • 🖨️ Reporte HTML — tabla imprimible, lista para PDF
  • 🗄️ JSON — datos completos para sistemas externos
5️⃣ Gestión de usuarios

Solo el Administrador puede gestionar usuarios. Ve a 👥 Usuarios en el menú.

  • Agregar usuario: clic en "+ Agregar usuario", llena el formulario y asigna el rol
  • Editar usuario: clic en ✏️ al lado del usuario
  • Eliminar usuario: clic en ✕ (no puedes eliminar tu propia cuenta)
  • Cambiar contraseña propia: clic en tu nombre (arriba a la derecha) → Cambiar contraseña
6️⃣ Configurar el sistema para otra institución

Puedes usar este mismo sistema para cualquier institución (hospital, ministerio, empresa, otro distrito). Cada institución tendrá su propia base de datos en Supabase.

PASO 1 — Crear proyecto en Supabase:

  1. Ve a supabase.com e inicia sesión
  2. Clic en "New project"
  3. Escribe el nombre del proyecto (ej. "hospital-central")
  4. Elige una contraseña segura para la base de datos
  5. Selecciona la región más cercana (ej. East US)
  6. Clic en "Create new project" — espera 1-2 minutos

PASO 2 — Obtener las credenciales:

  1. En el proyecto nuevo, ve a Settings → API Keys
  2. Clic en la pestaña "Legacy anon, service_role API keys"
  3. Copia la Project URL (empieza con https://)
  4. Copia la clave anon (empieza con eyJ...)

PASO 3 — Crear las tablas en el nuevo proyecto:

  1. Ve a SQL Editor → New query
  2. Copia y pega el SQL que aparece abajo
  3. Clic en "Run" — debe decir "Success"
CREATE TABLE IF NOT EXISTS visitas (
  id TEXT PRIMARY KEY, nombre TEXT NOT NULL, doc TEXT NOT NULL,
  tipo_doc TEXT, pais TEXT, nac TEXT, fecnac TEXT, sexo TEXT,
  tel TEXT, email TEXT, inst TEXT, cargo TEXT, ciudad TEXT,
  centro TEXT, motivo TEXT, persona TEXT, acomp INTEGER DEFAULT 0,
  obs TEXT, foto TEXT, metodo TEXT, registrado_por TEXT,
  entrada TEXT, entrada_iso TIMESTAMPTZ,
  salida TEXT, salida_iso TIMESTAMPTZ,
  estado TEXT DEFAULT 'Activa', fecha TEXT, mes TEXT, dia DATE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE TABLE IF NOT EXISTS usuarios_sistema (
  id TEXT PRIMARY KEY, nombre TEXT NOT NULL,
  usuario TEXT UNIQUE NOT NULL, pass TEXT NOT NULL,
  rol TEXT DEFAULT 'operador', color TEXT DEFAULT '#1976d2',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

PASO 4 — Configurar el sistema:

  1. En este sistema, ve a ⚙️ Configuración en el menú
  2. Cambia el nombre de la institución
  3. Pega la nueva URL de Supabase
  4. Pega la nueva Anon Key
  5. Clic en "🔌 Probar conexión" — debe aparecer en verde
  6. Clic en "📥 Descargar HTML configurado"
  7. Ese archivo descargado ya está listo para la nueva institución
✅ Resultado: Tendrás un archivo HTML independiente para cada institución, cada uno con sus propios datos en Supabase. Los datos de una institución nunca se mezclan con los de otra.
7️⃣ Tiempo real y múltiples usuarios

El sistema usa Supabase Realtime — cuando alguien registra una visita desde cualquier computadora, todos los demás usuarios la ven instantáneamente sin recargar la página.

  • El punto 🟢 en la barra superior indica conexión activa
  • El punto 🟡 indica que está reconectando
  • El punto 🔴 indica error de conexión — verifica el internet
  • Puedes tener múltiples computadoras y usuarios trabajando al mismo tiempo
8️⃣ Preguntas frecuentes

¿Los datos se pierden si cierro el navegador?
No. Todos los datos se guardan en Supabase en la nube.

¿Necesito internet para usar el sistema?
Sí, el sistema requiere conexión a internet para comunicarse con Supabase.

¿En qué navegador funciona mejor?
Google Chrome. También funciona en Edge y Firefox. Para la cámara QR se recomienda Chrome.

¿Cuántos usuarios pueden conectarse al mismo tiempo?
Con el plan gratuito de Supabase, hasta 50 conexiones simultáneas. Es más que suficiente para uso institucional.

¿Cómo hago copia de seguridad?
Usa el botón "⬇️ Exportar Excel" periódicamente. También puedes hacer backup desde el panel de Supabase → Storage → Database Backups.

¿Qué pasa si olvido la contraseña de admin?
Ve al SQL Editor de Supabase y ejecuta: UPDATE usuarios_sistema SET pass='nueva_clave' WHERE usuario='admin';
